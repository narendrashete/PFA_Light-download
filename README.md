# PFA Light — Downloads

PFA Light is the Prime Financial Accounting software for a single Windows computer. No server,
no internet connection and **no GitHub account** are needed.

## ⬇ Download

Go to **[Latest release](https://github.com/narendrashete/PFA_Light-download/releases/latest)**.
Under **Assets**, click one file:

| File | Use it if… |
|---|---|
| `PFA-Light-x.y.z-setup.exe` (**recommended**) | You want the app installed normally, with Start menu and desktop icons. |
| `PFA-Light-x.y.z-portable.exe` | You want to run it from one folder or a pen drive without installing. |
| `PFA_Light_Setup_Guide.pdf` | Step-by-step setup instructions with screenshots. |

**Requirements:** Windows 10 or 11 (64-bit), about 500 MB free disk space.

When you first run the exe, Windows may show **“Windows protected your PC”**. Click **More info → Run anyway**.
The app is safe; the warning appears because it is not code-signed yet.

## Moving from the old PFA (pfa.exe / nfa.mdb)

You can bring your data straight across from the old PFA program. No server is needed.

1. Close the old PFA program.
2. Open PFA Light. On the **Database** screen, choose **Import from old PFA (nfa.mdb)**.
3. Pick your `nfa.mdb` file. The password box is already filled in; change it only if your administrator
   gave you a different password. Then choose your company and click **Import**.
4. When the import finishes, **write down the one-time login passwords** shown on screen. Each user
   sets a new password at first login.

The old `nfa.mdb` is only read, never changed. Keep it as a backup until you are happy with PFA Light.
